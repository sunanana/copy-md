copy-md の設定

サイトが公開している Markdown 表示ページから取得する

サイトが Markdown の表示ページを公開している場合、末尾に .md を付ければ 直接 Markdown を取得できます。

例: デモ記事の通常ページと Markdown 化の URL
https://sunanana.github.io/copy-md/demo/article
https://sunanana.github.io/copy-md/demo/article.md

URL 追加拡張子 操作

登録がありません。この状態ではすべてのページが Jina AI Reader 経由になります。

Jina AI Reader の API キー

上の表に該当しないページを Markdown にするときだけ使います。

設定は chrome.storage.local にこの端末のみで保存されます。

API キーの取得方法

  1. https://jina.ai/ を開く
  2. Reader API のセクションで発行される jina_ で始まるキーをコピーする

無料トークンが取得出来ます。 なお無料トークンはレートリミットがある点にご注意ください。

Markdown を取得するまでの流れ

「サイトが公開している Markdown 表示ページから取得する」に登録したサイトは、外部サービスを利用しません。
ログイン認証が必要なサイトは、外部サービスからは閲覧できません。
